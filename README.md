# caretrack

设备资产登记与维修工单闭环的本地命令行工具。数据持久化在本地目录，无外部服务依赖。

需要 Go 1.24 或更新版本，仅使用标准库。

## 运行

```sh
go run . [--dir <数据目录>] <命令> [参数]
# 或先构建
go build -o caretrack . && ./caretrack --help
```

无参数、`--help`、`-h` 显示应用名与帮助；未知参数以非零状态退出。

## 命令

```sh
caretrack register <资产编号> <名称> <位置>      # 登记资产，初始状态“可用”；编号在数据目录内唯一
caretrack list                                  # 列出全部资产及状态；无记录时明确提示
caretrack show <资产编号>                        # 资产详情及未关闭工单编号
caretrack repair <资产编号> <故障描述> <请求标识>  # 报修，返回工单编号，资产变为“维修中”
caretrack close <工单编号> <维修结果>             # 关闭未关闭工单，设备恢复“可用”
caretrack history <资产编号>                     # 按时间顺序查看该资产的报修/关闭履历
```

## 数据目录

- `--dir <目录>` 选择数据目录（默认 `./caretrack-data`），不存在的目录会自动初始化，不同目录互不影响。
- 资产、工单、履历与报修去重信息在一次成功写操作（临时文件 + 原子重命名）中共同生效；校验或读写失败时非零退出，业务数据保持操作前状态。
- 数据文件损坏时报错并保留原文件，不会当作空库覆盖。

## 报修去重

- 请求标识用于同一数据目录内的报修去重，不是资产或工单编号。
- 相同标识 + 相同资产 + 相同描述的重放返回原工单及其当前状态（即使原工单已关闭或该资产已有新工单），不新增记录、不重开旧单。
- 相同标识搭配不同资产或描述会被拒绝；失败的新报修不会绑定请求标识。
- 每项资产最多一张未关闭工单；未知资产、空描述、重复关闭等均失败且不改动数据。
